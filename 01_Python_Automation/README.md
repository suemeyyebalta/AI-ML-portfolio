### 01-Stock Market Return Calculator

#### Project Description

Python-based calculator that automatically projects investment growth based on user-defines initial capital, annual return rate, and investment period. The tool calculates and displays the annual portfolio value using compound interest.

#### Skills Applied

Python, User Input, Data Type Conversion, Arithmetic Operations, For Loops, Range Function, F-Strings, Output Formatting, Compound Interest Calculation.

### 02-Automated Invitation Generation

#### Project Description

Development of a Python-based automation tool that reads a guest list of 20 recipients, generates personalized invitations for an annual company event, and automatically saves each invitation as an individual text file in a designated output folder.

#### Skills Applied

Python, Lists, For Loops, String Processing, F-Strings, Context Managers, File Reading & Writing, UTF-8 Encoding, OS Module, File Path Management, Automated File Generation, Document Automation.

### 03 – Automated File & Folder Organization

#### Project Description

Development of a Python-based automation tool that organizes files by their extensions, automatically creates corresponding subfolders, and moves files into the appropriate directories.

#### Skills Applied

Python, OS Module, Shutil Module, Directory Management, File Extension Detection, Conditional Statements, Automated File Sorting, File & Folder Automation.
